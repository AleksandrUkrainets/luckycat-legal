# LuckyCat Legal Documents

Official legal documents for the LuckyCat mobile game (`com.OlekU.LuckyCat`).

- [Privacy Policy](https://aleksandrukrainets.github.io/luckycat-legal/privacy-policy/)
- [Terms of Use](https://aleksandrukrainets.github.io/luckycat-legal/terms-of-use/)

The canonical English text files are stored in `documents/`. `legal-documents.json` records each document version, effective date, public URL, and SHA-256 checksum. Run `powershell -ExecutionPolicy Bypass -File ./build-pages.ps1` after changing a canonical text file or manifest; the generator verifies the checksums before writing the static pages.

The pages contain no advertising, analytics, cookies, tracking pixels, or third-party scripts.
